# 可学习模糊门控：训练与评价规范

版本：V3.1，2026-11-16。状态：设计规范，尚未训练。与 README.md、AI_TASK.md 一起使用。

## 1. 训练什么，保留什么

冻结 Qwen 与 DeBERTa 权重；冻结 BM25、关系记录、局部 NLI 与缺口查询代码/提示词后，训练一个小型零阶 Sugeno 模糊收益预测器。它根据首轮信号预测“采用固定补查分支后答案 F1 的变化”，再结合预算决定行动。推理时不知道实际补查收益，也不能访问 gold。

这是监督学习一个小门控模型，不是微调大语言模型，也不是训练新的 NLI 基座。固定规则结构+梯度学习参数可称为可学习的模糊推理系统；无需声称复现某篇 ANFIS 的全部结构、混合优化或提出新算法。参数少有助于有限数据下控制过拟合，并不保证效果。

## 2. 监督来自同题的两条实际分支

对每个训练问题及其固定候选池保存：

- A：首轮两段材料上的答案与句级引用。
- B：由相同 A/关系记录生成缺口查询，固定检索一段后重新作答的答案与引用。
- x：只从 A 阶段可见内容计算的 r（NLI支持风险）、g（关系覆盖缺口）。
- y=F1(B)-F1(A)，范围 [-1,1]，保留改善、持平和退化的连续幅度。
- A/B 的官方分数、完整调用记录、共同成本和 B 追加成本，均由训练/评价程序另存。

例如 A=.0、B=1，则 y=1；A=1、B=1，则 y=0；A=1、B=.5，则 y=-.5。这些是虚构示意值。不能用低 NLI 分数或 Qwen 自我评价作监督标签。不要把所有 y>0 等同同样收益，也不要把 y=0 与 y<0 混成同样损害。

所有训练/开发题都生成 A 和 B，而非只在当前门控触发时生成 B，以避免只观察被选题的收益。B 的提示词、查询和检索策略一旦变更，其标签与缓存失效；不得沿用旧 B 标签训练新补查策略。

训练程序可以访问 y；在线 score() 只能接收白名单 x 和版本身份。B内容、B分数、gold答案、gold支持句、金标覆盖率均不得进入 x。候选池总长度可作成本估计分组信息，第一版不作为额外学习特征。

## 3. 数据划分与生成规模

已有数据不能自动叫作“全新未见数据”。V2 pilot 的一部分用于50题工程原型；V2原500道tune按qid固定哈希拆成约400道V3训练和100道V3验证。因原500题已用于历史开发，要在论文中说明其身份；它们只能支持新最终集之外的开发和训练。

先在上述训练/验证池内分别取100/50题做训练代码与成本烟雾测试，再按实际预算扩大到400/100。50题原型与正式训练/验证池尽量分开；若有复用需明确它只属于开发，不当独立评价。所有训练超参和阈值只用训练/验证集确定。

另从未参与任何历史实验/人工诊断的ID中封存V3最终集，初始费用规划候选为300题；数量在看最终分数前按资源与精度需求锁定。不得先看300题成绩再扩至500题追求显著。

第一版先在一个主要文本规模训练（30或60段，依据P0长度/算力可行性在看成绩前确定），再用同一个门控评价10/30/60段中的可行规模。验证集可以校准各规模的运行边界，必须标注为“固定模型、按规模校准阈值”，并另报使用统一边界的结果。不要偷偷为每个规模重新训练后宣称跨规模泛化。

如果后续混合多种规模训练，同一个qid的所有规模、顺序和生成副本必须属于同一划分；不能按行随机切分。每个qid总权重相同，防止有更多规模副本的题被重复加权。书本题仅作外部演示/测试，第一版不混进训练数据；需训练书本模型时另按来源隔离。

400道训练题对两个输入、八个参数的小门控可作为可行起点，不是足够泛化或胜出的保证。报告y的正/零/负分布和基线方差；有效改善题过少时，不靠增加网络深度掩盖问题。

## 4. 模糊模型的可执行定义

第一版两个输入x=(r,g)，均在[0,1]。关系/NLI失败状态先沿用预先固定的回退，不在训练中偷偷删除；单独报告可训练有效输入的覆盖率和含回退的整条系统成绩。

每个输入j使用可学习的高隶属函数：

```text
mu_H(x_j) = sigmoid((x_j-m_j)/t_j)
mu_L(x_j) = 1-mu_H(x_j)
m_j = sigmoid(a_j)
t_j = 0.05 + 0.45*sigmoid(b_j)
```

m_j为转折中心，t_j为平滑宽度；这里的数值上下界是工程设计，非已经验证的最优范围。两输入各两个参数，共四个隶属函数参数。它们是隶属度，不是正确率。

保留四条规则：LL、LH、HL、HH，激活度为对应隶属度的乘积。每条规则有一个可学习后件c_k=tanh(u_k)，范围[-1,1]。预测：

```text
w_LL = mu_L(r)*mu_L(g)
w_LH = mu_L(r)*mu_H(g)
w_HL = mu_H(r)*mu_L(g)
w_HH = mu_H(r)*mu_H(g)
pred_delta = sum_k(w_k*c_k) / max(sum_k(w_k), 1e-8)
```

总共8个标量参数：a_r,b_r,a_g,b_g,u_LL,u_LH,u_HL,u_HH。score不是“补查概率”，而是预测F1增量。

因L/H互补，完整输入时权重和理论上为1；单测验证这一不变量。风险高不一定补查更有益，因此不强制学习后的c_LL<=c_LH等排序，不把未验证的单调性写成事实。展示规则时明确每个后件表示预测收益，允许负值，不能把负数显示成概率。

## 5. 损失、优化与可复现记录

主训练目标：

```text
L = mean_i((pred_delta(x_i)-y_i)^2) + alpha*mean(theta^2)
```

theta是上述8个原始参数。默认普通MSE，保留真实收益幅度；不默认过采样改善题或用不平衡类别权重，否则会改变平均收益估计的含义。若探索加权损失要单列并在验证集选择，不能与主MSE结果混报。

起始配置：CPU float32、Adam、batch_size=32、lr=0.01、max_epochs=300、每epoch验证一次、patience=30；alpha候选{0,1e-4,1e-3}。这些是建议的开发配置，不是已运行结果。训练种子{17,42,73}；记录每次训练而非只留最好一次。初始化m=.5、t=.15，四后件初始化为训练集y均值附近的小扰动（仅用train）。

以验证MSE早停；每个alpha选各种子验证MSE的均值，预先固定均值并列时选正则更强者。主模型对所选alpha的三个种子分别报告结果；若需要部署一个checkpoint，预先规定使用seed42，不根据最终集挑seed。开发决策与最终集解封完全分开。

同时记录train/val损失、收益预测误差、规则参数轨迹、梯度/数值状态、正/零/负y分组误差。训练后保存weights.pt、model_spec.json、history.csv、train_manifest.json、validation_report.md。weights明确包含学习参数，不能仅保存阈值文件然后称为训练。

若模型退化为接近常数，检查标签稀疏、输入无区分力和噪声；如实与常数均值预测比较。不得反复扩大网络/换标签直到赢。

## 6. 从预测收益到成本约束决策

第一步分开“学习收益”和“校准行动”：模型预测delta；在验证集针对几个补查比例目标（10/20/30/50%）确定score边界，锁定后在测试逐题决策，报告实际触发率。不同方法使用相同目标和校准程序。

第二步给出质量–成本曲线：统计每个边界的实际累计Qwen输入/输出、NLI和耗时。不能因每个方法补查数量接近，就声称总token相同；关系提取和核验是公共额外开销，必须计入。

可选成本敏感决策，在基础模型验证通过后增加：

```text
utility_score = pred_delta - lambda * estimated_extra_Qwen_input_tokens/1000
```

lambda表示愿意为每1000追加输入tokens支付的F1代价；用固定开发网格校准，测试前锁定。estimated_extra只能来自已知上下文长度和训练集成本统计，或一个仅在train训练的简单成本估计器；不能用已完成B的实测费用来冒充在线可知特征。验证估计误差，实际总成本仍另测。预先计算B只用于离线反事实评价。

安全的硬预算执行：每次调用前用实际tokenizer计算该次完整输入长度并检查累计额度；必要时不执行B或选句调用，保留可输出答案并标记budget_exhausted。对未知的未来调用不能保证全部执行，必须报告预算耗尽/输出不完整率。输出tokens和NLI另有上限。预算未达到不代表应该用完。

训练标签不包含引用充分性，故不能仅凭该模型的训练目标声称引用更完整；引用评价独立报告。若日后改多目标标签，另立规范并重建train/val。

## 7. 必须有的训练对照与消融

1. 常数均值收益预测器：排查模型只学到大多数题没收益。
2. 相同r/g输入的线性收益回归（可用Ridge，正则仅验证选择）：与Sugeno同样预测连续delta。
3. 可选逻辑回归分类器：y>0为正，作为传统“选改善题”对照；其目标与收益回归不同，要注明，不能宣称所有方法用了同损失。
4. 人工/小网格校准的固定Fuzzy（旧版规则结构、同一新信号），与训练Fuzzy比较。
5. 只训练4个后件、固定隶属函数，比较完整8参数训练；判断学习隶属函数是否值得。
6. NLI单信号与去关系覆盖的模型：开发重新校准预算，含回退的全体结果计入。

Full、固定检索、Qwen自检等整系统基线继续保留。所有学习门控共享相同train/val、x、A/B、校准程序及最终题；每条方法各自实际需要的调用计入成本。

主要对照：训练Fuzzy vs 固定Fuzzy；训练Fuzzy vs Ridge。同时说明新旧核验/查询带来的独立贡献。三种子预测分别输出，统计区间按qid配对，不能把同题三种子当三个独立样本。资源允许时对每个预定seed报告同题bootstrap区间，或另报固定seed42主区间与种子波动；在最终集运行前选定口径。

## 8. 训练不是本项目最昂贵的阶段

8参数门控拟在CPU训练并实测时间，不为它单独租大GPU。主要资源消耗是为训练/验证/最终题生成A/B答案、关系记录和NLI分数。先做100train/50val烟雾与费用估算，再扩大。

训练是离线一次性工作，部署问答的每题成本不包含反复训练；但报告训练总生成量、训练计算成本和推理每题成本，避免只报部署节省而隐藏数据生成开销。若需要宣称总使用成本划算，应按调用次数给出摊销/回本分析。

## 9. 训练实现的关键验收

- 训练后真实权重变化、loss有定义、可反向传播且梯度有限；参数边界保持有效。
- 读取保存权重后预测一致，缓存版本与特征顺序匹配；门控训练不产生额外LLM调用。
- 按qid/group划分，无训练/验证/测试交叉；在线特征无B/gold字段；未知/解析失败仍有回退。
- 每题A/B身份和标签可从官方评分重算；补查策略/提示改变时阻止旧标签混用。
- 低于常数基线/线性基线也如实报告。训练成功指优化/复现正确，不等于研究假设成立。
