# V3.1 开发阶段结果

| 阶段 | 关键记录 | 来源 |
| --- | --- | --- |
| P0 实机容量 | 4,096 与 8,192 在 4 GiB CPU offload 下通过。16,384 改用 6 GiB 后通过。 | [实机验收](p0/gpu_runtime.md) |
| P1 数据 | 50 道开发题、150 个候选池和 1,050 条提示长度记录。金标与在线输入分文件存储。 | [数据说明](p1/README.md) |
| P1.5 30 段池 | 两阶段 2+4 的答案 F1 为 59.92%，全文直读为 56.73%。配对差为 +3.19 个百分点，探索性 95% 区间 [−11.27, +17.77]。平均输入 token 分别为 1,316 和 4,341，平均实际延迟分别为 23.59 和 32.47 秒。 | [策略预检报告](p1_5/REPORT.md) |
| P2 30 段池 | 在相同最终材料下，直读 2+4 和两阶段 2+4 的答案 F1 均为 59.92%。平均输入分别为 948.92 和 1,316.44 token，请求均值分别为 13.04 和 23.59 秒。 | [同材料直读](p2/REPORT.md#同材料直读) |
| P2 关系级核验 | 约束复测通过结构校验 48/50，接受的 121 条引用均可定位。20 道完整评审题中，明确判定的关系忠实率为 26/56（46.43%），未达到 90% 门槛。 | [人工验收](p2/REPORT.md#人工验收结果) |
| P3 回退路线 | 训练集 A/B F1 为 40.56%／50.38%（100 题），验证集为 44.07%／60.47%（50 题）。保存逐题成本和首轮特征。 | [试跑报告](p3/REPORT.md) |
| P4 小规模试训 | 主 Sugeno 验证 MSE 为 0.15454，线性收益回归为 0.15887。两者在 10%、20%、30%、50% 补查预算下分别选中相同题，F1 为 48.33%、54.33%、54.00%、60.27%。 | [验证报告](p4/validation_report.md) |
| P5 正式评估 | 300 道封存题、30 段、20% 目标补查预算：Sugeno 44.64%、固定 Fuzzy 43.64%、线性回归 44.64%。Sugeno 对固定 Fuzzy 为 +1.00 个百分点，95% 区间 [−1.33, +3.33]；对线性回归逐题动作相同。 | [正式报告](p5/REPORT.md) |
| P5 成本与盲审 | 6,440 次 Qwen 请求、4,511,421 输入／91,426 输出 token；50 题端到端平均 20.60 秒、P95 28.44 秒。盲审完成度 0／60，双评 0／20，待回收。 | [运行验收](p5/REPORT.md) |

P1.5 与 P2 基于同一批已用开发题。P4 使用源于历史 V2 tune 的试跑划分，50 道验证题参与早停、超参选择和预算诊断。P4 的时延来自 P3 实测分量的离线回放。P5 的正式机测已完成，人工盲审仍待回收。
